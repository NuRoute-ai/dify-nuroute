# Privacy Policy

This plugin sends the data you configure in Dify (prompts, conversation history, and any tool
definitions) directly to the NuRoute gateway URL and API key you provide in the model's
credentials. It does not send data anywhere else, and does not collect, log, or store any data
of its own — all requests pass straight through to your NuRoute gateway.

Your NuRoute gateway's own data handling is governed by NuRoute's privacy policy:
https://nuroute.ai/privacy

Your API key is stored by Dify itself, encrypted, the same way it stores credentials for any
other model provider — this plugin does not persist it independently.
